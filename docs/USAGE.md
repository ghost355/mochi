# Как собрать и чем управлять

Практическая инструкция по текущей прошивке. Технические подробности — в
[README](../README.md), здесь только то, что нужно, чтобы собрать макет и
пользоваться роботом.

## Что нужно

| Деталь | Примечание |
|---|---|
| Waveshare RP2350-USB-A | RP2350A, 2 МБ flash |
| OLED 1.3" 128×64 | SH1106, I2C, адрес 0x3C |
| TTP223 | ёмкостный датчик, выход push-pull |
| Пассивный пьезо-бузер | именно пьезо-диск, не магнитный |
| Макетка, провода | |

Пьезо — это конденсатор: ток через ножку идёт в миллиамперах, поэтому он
садится на GPIO через резистор 100 Ом. **Магнитному** бузеру (катушка, десятки
ом) нужен транзистор и диод.

## Подключение

Перед любым переподключением **обесточь плату** — вынь USB.

| Модуль | Плата | Примечание |
|---|---|---|
| OLED VDD | 3V3 | не 5V: у модуля свой стабилизатор, от 3V3 он просто не греется |
| OLED GND | GND | |
| OLED SDA | GP4 | |
| OLED SCL | GP5 | |
| TTP223 VCC | 3V3 | выход push-pull, подтяжка не нужна |
| TTP223 OUT | GP2 | |
| TTP223 GND | GND | |
| Браузер + | GP3 | через 100 Ом |
| Браузер − | GND | |

```
        RP2350-USB-A                    OLED (SH1106)
     +---------------+                 +--------------+
     |          3V3  +-----------------+  VCC         |
     |          GND  +-----------------+  GND         |
     |     GP4 (SDA) +-----------------+  SDA         |
     |     GP5 (SCL) +-----------------+  SCL         |
     |               |                 +--------------+
     |      GP2  +--------------------- TTP223 OUT
     |      GP3  +---[100R]------------ piezo +
     |          GND  ------------------ piezo -
     |   GP0/GP1     UART0 debug (опционально)
     +---------------+
```

> Питание — только через **USB-C**. Разъём USB-A на этой плате это *хост*
> PIO-USB: если подать в него 5 В, пока воткнут USB-C, два источника начнут
> бороться друг с другом.

## Прошивка

1. Держишь **BOOT**, втыкаешь **USB-C**, отпускаешь **BOOT**.
2. Появляется диск `RPI-RP2`.
3. Копируешь `build/mochi.uf2` на диск. Плата сама перезагрузится.

Сборка описана в [README](../README.md#build). Кратко:

```sh
export PICO_SDK_PATH=~/pico-sdk
cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build -j8
```

## Загрузка

~3 секунды: лицо приходит спящим, веки поднимаются с замедлением, зрачок из
размытого диска схлопывается в звёздочку, играет короткое арпеджио. Касания в
это время игнорируются — робот ещё не проснулся.

## Жесты

Окна тапов перекрываются, счёт идёт от большего к меньшему.

| Тапов | Окно | Что происходит |
|---|---|---|
| 1 | — | любопытство: глаза шире, зрачок мечется, брови вверх, 2.5 с |
| 2 | 1.2 с | радость: нижнее веко поджимает глаз снизу, брови высоко, 4 с |
| 3 | 2.0 с | внимание (лицо любопытное), таймер **не** запускает |
| 3 + удержание | 0.5 с | **помодоро 25 минут**, повтор — отмена |
| 4 | 3.0 с | раздражение: веки под углом, брови вниз-внутрь, 3 с |
| 5 | 3.0 с | просящее: брови домиком, глаза широко, 4 с |
| 6 | 3.5 с | паника: лицо 132%, глаза в края экрана, зрачки-точки, 2.6 с |

Помодоро запускается **только удержанием третьего тапа**. Иначе серия из 4–6
тапов по дороге к панике тихо оставила бы таймер работать.

## Удержание

| Сколько держишь | Что происходит |
|---|---|
| 0.5 с (после трёх тапов) | помодоро старт/отмена, остальные реакции не срабатывают |
| 0.7 с | прищур + низкий дрон 196 Гц, тянется пока держишь |
| 1.5 с | злость: монобровь, веко 34% под 28°, дрон продолжается |
| 2.0 с | сверху появляется баннер `РУКИ УБРАЛ!` |
| отпустил | моргание + мелодия отпускания, звук замолкает |

## Сон и пробуждение

45 секунд без касаний: робот отрыгивается (10–14 низких импульсов со
сползанием 115 → 60 Гц), затем играет колыбельная, пока веки опускаются.
Во сне глаза полуприкрыты двумя веками.

Любое касание будит: зевок (зажмурился, распахнул, осел) и звук зевка.

## Помодоро

Три тапа, третий держишь — лицо становится сосредоточенным, в нижних трёх
строках ползёт полоса: примерно пиксель за 12 секунд, всего 25 минут. Робот в
это время не засыпает, даже если его не трогать. Тап во время работы временно
меняет лицо, потом рабочее выражение возвращается.

Время вышло: полоса стирается, лицо радуется, играет арпеджио.

## Звук

| Когда | Что |
|---|---|
| каждый тап | чириканье в духе R2-D2, 4 разных рисунка, выбор случайный |
| раздражение, злость | грустный мотив |
| удержание | низкий дрон 196 Гц |
| отпускание | мелодия отпускания |
| загрузка, конец помодоро | арпеджио 650 мс |
| засыпание | отрыжка, затем колыбельная |
| пробуждение | зевок |

Звук полностью неблокирующий: играет в фоне, кадры не тормозит.

## Консоль

USB CDC (или UART0 на GP0/GP1, 115200):

```
boot: mochi M1
I2C found 0x3C
display: SH1106 @ 0x3C
fps=50 upd=4
mood: curious
touch: tap (2)
focus: start 25 min
```

`upd` — сколько из 50 кадров реально отправили пиксели на панель. Близко к
`fps` — что-то постоянно движется; 0 — анимация встала.

## Если что-то не так

**Экран чёрный, в консоли `I2C: no devices`.** Проверь SDA/SCL местами
(классика), питание модуля и адрес: часть модулей сидит на 0x3D. Драйвер
подхватывает первый найденный адрес, но если шина пустая — пробует 0x3C.

**Экран белый или в мусоре.** Модуль не пережил инициализацию: проверь, что
это SH1106, а не SSD1306 (у них разная адресация страниц). Драйвер
рассчитан на SH1106.

**Двоятся брови, над лицом висят чёрточки.** Это была ошибка отправки
региона, исправлена. Если появится снова — значит какой-то элемент рисуется
выше строки 8 и залезает в страницу баннера; ловится тестом:
`cd tools/preview && make check`.

**Датчик не реагирует.** TTP223 после подачи питания калибруется ~1 секунду,
первые касания игнорируются. Если совсем молчит — проверь, что OUT это GP2 и
что перемычка на модуле не переводит его в режим toggle (тогда он работает
как выключатель, а не как кнопка).

**Звук тихий.** Пьезо-диск без резонатора слышно плохо; это нормально для
такого излучателя. Громче делается не амплитудой, а резонансом: подклей диск
к кусочку пластика или поставь в корпус.
